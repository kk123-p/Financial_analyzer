一、项目概览

Financial Analyzer Pro 是一个集财务数据获取、多维度分析、量化策略回测、AI 深度投研于一体的综合平台。系统采用递进式 6 阶段分析流水线，覆盖从行情概览到投资评级的完整决策链路。架构上分为三层：数据层（多源适配 + 缓存）、分析层（16 个分析器 + 7 类量化因子）、展示层（FastAPI Web UI + htmx 动态渲染 + ECharts 可视化）。

项目源于《Python大数据财务分析》（2023版）的教科书算法体系，将其中 6 个核心方法工程化为可复用的流水线模块，同时扩展了专业的量化多因子引擎和基于 DeepSeek LLM 的 AI 投研辩论系统。

多源数据适配

Tushare / akshare / YFinance / 新浪财经四源自动切换，覆盖约 40 种数据维度

递进式分析

6 阶段流水线，34 项分析，从行情概览到 DCF 估值 + 投资评级

AI 三方辩论引擎

价值 × 成长 × 风控三位分析师 3 轮辩论，基于 DeepSeek API 流式生成研报

量化多因子引擎

7 类 29 个因子，支持回测、绩效归因、风险控制和模拟交易

32 维度审计检测

插件式信号系统，覆盖资产/利润/现金流/交叉验证/治理/模型 6 大维度的异常检测

ML 舞弊识别

决策树 / 随机森林 / GBDT / XGBoost + 投票集成，基于真实 A 股舞弊数据集训练

三、分析流水线

系统定义了 6 阶段 34 项递进式分析流水线，从数据概览到最终投资评级逐层深入：

阶段分析项目覆盖内容
1. 数据概览行情概览、价格趋势、量价结合K线、均线、成交量、动量
2. 财务体检资产负债表、利润表、现金流量表、财务比率、趋势评分三表完整分析 + 比率 + 同比趋势
3. 股东与资金股东结构、资金流向、分红分析十大股东、北向资金、融资融券
4. 深度诊断杜邦分析、自由现金流、护城河评估、综合深度ROE拆解、FCFF、Z/F/M-score
5. 风险审查审计检测、ML欺诈检测、风险评估32 信号 + ML 集成模型 + 行业阈值
6. 估值评级综合投资评级、PE/PB-ROE、EV/EBITDA、DCF加权评分 + 三情景 DCF + 投资论点

五、AI 投研系统

两层 AI 体系，基于 DeepSeek API（兼容 OpenAI 格式），支持思考模式和流式输出。

5.1 辩论引擎 (DebateEngine)

三维角色 3 轮辩论，产出冲突-共识-行动建议结构化报告：

角色风格关注维度权重
价值分析师格雷厄姆式安全边际、PB、PE、股息率、清算价值33%
成长分析师费雪式营收增速、研发投入、护城河、TAM33%
风控分析师巴菲特式杠杆率、现金流质量、管理层诚信、尾部风险33%

5.2 信号检测器 (SignalDetector)

20+ 可触发信号：盈利质量预警、增长透支预警、纸面富贵、存贷双高、长贷短投、经营恶化、商誉暴雷风险、大股东掏空风险等。集成 ML 欺诈检测管线进行交叉验证。

5.3 提示词系统

6 个预置分析模板 + 哈佛分析框架 + 三表联动验证 + 生命周期框架 + 5 类预警清单。支持用户自定义模板持久化存储。

六、量化多因子引擎

完整的量化交易系统，覆盖因子计算 → 组合构建 → 回测 → 归因 → 风控 → 模拟交易全流程。

6.1 因子体系 — 7 类 29 个因子

类别因子方向
价值PE、PB、PS、股息率、FCF收益率、EV/EBITDA多/空
质量ROE、ROIC、毛利率、净利率、Piotroski F-score、应计比率多
成长营收增速、净利增速、现金流增速、ROE 趋势多
动量3月动量、6月动量、12月动量多
情绪北向资金流向、融资余额变化多
低波60日波动率、120日最大回撤、下行波动率空
风险负债率、流动比率、对数市值、平均换手率空

6.2 回测引擎

月度调仓循环，支持交易成本（佣金 0.1% + 印花税 + 滑点）、T+1 限制、涨跌停检查。使用 ThreadPoolExecutor 并行获取数据。

6.3 风险控制

最大回撤阶梯减仓 + 个股/组合止损止盈 + 组合波动率监控。

七、审计异常检测系统

插件式架构，装饰器注册，6 个维度 32 个信号：

维度信号数检测内容
资产端8应收激增、存货积压、商誉过高、在建工程延迟结转、其他应收异常等
利润端4收入质量、毛利率异常、非经常性损益依赖、减值损失异常
现金流4经营现金流与利润背离、筹资依赖、投资异常、结构-生命周期错配
交叉验证5营收↔税费、营收↔人工、资本支出↔折旧、投资收益↔长期资产等
治理5审计意见、高管变动、关联交易、股权质押、分红异常
模型6Z-score、F-score、M-score、现金转换周期、营运资本、杠杆率

每个信号按等级（高/中/低/信息）和类别组织，输出结构化的 AuditStructuredResult 包含诊断描述和风险摘要。

九、数据层

9.1 多源适配策略

数据源优先级覆盖范围需要凭证
Tushare1（主力）A 股全面数据（行情/财务/资金/股东）Token
akshare2（备选）A 股 + 宏观经济数据无
YFinance3（备选）美股数据无
新浪财经4（兜底）A 股日线行情无

9.2 缓存策略

双层缓存：内存字典（热数据，毫秒级读取）+ SQLite 持久化（温数据，跨会话复用）。线程安全的 threading.Lock 保护，支持 TTL 配置和自动过期清理。

9.3 数据归一化

DataNormalizer 将四个数据源的异构列名统一为标准化格式（StandardColumns），下游分析器无需关心数据来源。
