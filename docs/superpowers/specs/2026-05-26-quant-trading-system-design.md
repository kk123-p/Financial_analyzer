# 全自动量化交易系统 — 设计规格

## 概述

在现有 Financial Analyzer Pro 基础上，新建独立的 `quant/` 模块，实现基于多因子模型的半自动量化交易系统。仅自然复用数据接入层和基础设施，策略核心从零构建。

## 关键决策

| 决策项 | 选择 |
|--------|------|
| 策略方向 | 多因子融合（基本面 + 技术面 + 情绪面综合打分） |
| 执行模式 | 半自动：系统出信号 → 人工审核 → 一键确认下单 |
| 选股池 | 自定义多池：核心池（沪深300）+ 成长池（创业板/科创50）+ 红利池，渐进开发 |
| 因子类别 | 7类：价值、质量、成长、动量、情绪、低波动、风险 |
| 调仓频率 | 每月，月末计算信号，次月首个交易日执行 |
| 券商接入 | 阶段一仅信号+模拟盘，后续接 EasyTrader |
| 组合持仓 | 5-8只，适度分散，附股价过滤（≤15元优先） |
| 起步资金 | 5000元人民币 |

## 核心范式转变

从"单股深度分析"转向"全市场截面批量排名"：

| 维度 | 旧 (Financial Analyzer) | 新 (Quant Trader) |
|------|------------------------|-------------------|
| 分析对象 | 单只股票，深度分析 | 全市场800+只，批量排名 |
| 输出 | 分析报告（文本+图表） | 买入/卖出信号 + 仓位权重 |
| 数据流 | 用户输入代码 → 拉取数据 → 分析 | 定时批量拉取 → 因子矩阵 → 排名 → 信号 |
| 核心方法 | 财务指标逐一计算展示 | 截面标准化 + 加权打分 + 约束优化 |

## 系统架构（5层）

```
❶ Web 交互层
   策略面板 / 信号列表 / 模拟持仓 / 绩效图表
   扩展 SPA 前端，新增 quant/ 视图

❷ 信号引擎层 [全新核心]
   因子矩阵 → 截面排名 → TOP-N → 约束过滤 → 调仓清单

❸ 计算层
   ❸a 因子计算层    — 7类因子 · 批量计算
   ❸b 回测引擎      — 月频调仓 · 绩效归因
   ❸c 模拟持仓      — 虚拟交易 · 损益跟踪

❹ 数据接入层 [自然复用]
   Tushare/AKShare/Sina 多源适配 · SQLite缓存 · 数据标准化

❺ 存储层 [扩展]
   选股池表 · 因子矩阵表 · 信号历史表 · 模拟持仓表 · 绩效快照表
```

## 信号引擎流程

```
选股池(800只) → 7因子计算 → 截面标准化(Z-score·行业中性)
→ 加权总分 → TOP-30排名 → 硬过滤(ST·次新·停牌·股价>15元)
→ 约束优化(5-8只·≥3行业·单行业≤40%·现金预留10%)
→ 调仓清单(买入/卖出/加仓/减仓)
```

## 因子定义

### 价值因子
PE（市盈率）、PB（市净率）、PS（市销率）、股息率、FCF Yield（自由现金流收益率）、EV/EBITDA

### 质量因子
ROE（净资产收益率）、ROIC（资本回报率）、毛利率、净利率、Piotroski F-Score、应计利润比例

### 成长因子
营收同比增速、净利润同比增速、经营现金流同比增速、ROE趋势（3年）

### 动量因子
3/6/12个月价格动量、成交量动量、行业相对强度

### 情绪因子
北向资金净流入（月）、融资净买入（月）、机构持股比例变化（季）、股东增减持方向

### 低波动因子
历史波动率（60/120日）、Beta系数、下行标准差、最大回撤（120日）

### 风险因子
资产负债率、流动比率、总市值对数、日均换手率（流动性）

## 特殊约束（5000元本金适配）

- **股价过滤**：自动排除股价 > 15元的标的
- **最小可买检查**：确保每只至少能买100股（1手），单只最低仓位500元
- **ST过滤**：自动排除 ST/*ST/退市风险警示股票
- **次新股过滤**：排除上市不满6个月的股票
- **停牌过滤**：排除当前停牌的股票
- **行业分散强制**：至少覆盖3个行业，单行业不超过总仓位40%
- **现金预留**：保留5-10%现金

## 开发阶段

### Phase 1 — 因子+信号引擎
**目标**：每月生成一份经过约束过滤的调仓清单  
**新建代码量**：~1200行  
**交付物**：
- 选股池管理
- 7类因子批量计算
- 因子矩阵 → 截面标准化 → 加权打分 → TOP排名
- 硬过滤 + 约束优化 → 调仓清单
- 前端信号面板

### Phase 2 — 回测验证
**目标**：用3-5年历史数据验证策略有效性  
**新建代码量**：~800行  
**交付物**：
- 月频调仓回测循环
- 绩效指标（夏普比率、最大回撤、年化收益、胜率）
- 因子绩效归因
- 前端绩效面板

### Phase 3 — 模拟交易 + 实盘接入
**目标**：模拟验证后接入 EasyTrader  
**新建代码量**：~600行  
**交付物**：
- 模拟持仓与虚拟盈亏跟踪
- EasyTrader 下单适配
- 人工审核确认流
- 风险熔断机制

## 技术约束

- 因子计算基于 pandas/numpy，不做分布式
- 回测仅支持月频调仓
- 暂不考虑日内数据和实时行情
- 前端保持 Vanilla JS SPA 架构
- 数据库沿用 SQLite
